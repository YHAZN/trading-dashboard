## Free-shipping meter: unified (evening round)

### Problem Boss flagged
1. PDP ship meter didn't update when selecting a different variant (showed first-variant price only).
2. PDP meter didn't know what was already in cart, so customers near the threshold got misleading messaging.
3. Cart drawer had a hardcoded `FREE_SHIP_THRESHOLD_CENTS = 3500` in `theme.js` with no link to any theme setting.
4. Cart drawer always said "🎉 You unlocked free US shipping" regardless of cart total (looked like it, but really: the message was only re-computed on drawer refresh, and the UI/threshold value was divorced from the PDP one).
5. `/cart` page had no progress bar at all.

### Fix shipped (commit `b84d155`, pushed)

**New snippet:** `snippets/ship-meter.liquid` — single source of truth for the component across PDP, drawer, cart page.

**Global setting:** `Theme settings → Shipping (shared)` with:
- `free_shipping_threshold` (USD, default 35)
- `free_shipping_unlocked_label` (editable)
- `free_shipping_progress_label` (editable, supports `{amount}` token)

**Contexts:**
- `product` — reads variant price via `data-product-price-cents`, adds live cart total client-side. Updates on `variant:change` via `ShipMeter.setProductVariantCents(price)` hook inside `initVariantSync`.
- `drawer` — cart total only. `CartDrawer.renderShipping()` now just calls `ShipMeter.updateAll(cart.total_price)`. Meter hidden when cart empty via `ShipMeter.hideDrawerMeter(true)`.
- `cart` — SSR on load, hydrated by `ShipMeter.init()` fetching `/cart.js`.

**JS module:** `ShipMeter` (added at top of `theme.js` before `CartDrawer`)
- `updateAll(cents?)` — updates every `[data-ship-meter]` on page using cached cart total + per-meter context.
- `setProductVariantCents(cents)` — PDP-only, wired to variant select.
- `hideDrawerMeter(bool)` — drawer empty-state.
- `init()` — hydrates on DOMContentLoaded.

**Cleanup:**
- Removed hardcoded `FREE_SHIP_THRESHOLD_CENTS` constant from `theme.js`.
- Removed per-section `free_ship_threshold` from `main-product.liquid` schema (replaced with a paragraph pointing to theme settings).
- Removed orphaned `"free_ship_threshold": 45` from `templates/product.json` (had a merge conflict — Shopify editor had written 45 while I was working).
- Unlocked state styling (green) now shared via `.ship-meter.is-unlocked` — matches previous drawer look.
- Per-context spacing via `.ship-meter--drawer` and `.ship-meter--cart`.
